# 交付说明（v1.5.0）

这一页是给验收方看的：**拿到仓库之后做什么、怎么确认它是好的、哪些东西刻意没做**。
实现细节与设计取舍在根目录 [README](../README.md)，逐版本变更在 [CHANGELOG](../CHANGELOG.md)，
上线操作手册在 [PRODUCTION.md](PRODUCTION.md)。

- 交付物：一个可直接导入微信开发者工具运行的充电桩小程序，外加一套可部署的后端。
- 交付状态：**可交付**。默认数据源 `local`，不装依赖、不起服务、不联网即可完整演示。
- 运行时依赖：**0 个**（小程序与后端都是）。`package.json` 只用于校验、测试与文档生成脚本。

## 演示 vs 上线：这份交付到哪一步了

| 维度 | 演示（默认配置，开箱即用） | 上线（需要额外动作） |
| --- | --- | --- |
| 数据来源 | 本机 mock + Storage，断网可用 | 后端 `server/`，文件持久化，重启不丢 ✅ 已实现 |
| 登录 | 无（不发任何请求） | `wx.login` → 自签令牌，按账号隔离数据 ✅ 已实现 |
| 部署 | 不需要 | Docker / systemd + Nginx HTTPS ✅ 已实现 |
| 加固 | 不适用 | 限流、体积限制、CORS 白名单、优雅退出、健康检查 ✅ 已实现 |
| 充电过程 | 60 倍速仿真 | 真实充电桩协议 ❌ **未接入** |
| 支付 | 余额沙箱（响应带 `sandbox: true`） | 真实微信支付 ❌ **未接通**，见 [PRODUCTION.md 第六节](PRODUCTION.md#六接入微信支付) |
| 小程序资质 | 测试号 `touristappid` | 认证小程序 + 备案域名 + 后台配置 ❌ **需人工完成** |
| 开票 / 客服 | 本机记录 / 演示号码 | 真实通道 ❌ **未接入** |

一句话：**后端骨架已经是生产形态，业务侧的「钱」和「电」两条真实链路还没接。**
本轮把「能靠写代码解决的」都解决了，剩下的都是需要人工申请资质或对接外部系统的。

## 一、五分钟上手

### 只看小程序（默认，推荐）

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)稳定版。
2. 「导入项目」→ 目录选**本仓库根目录** → AppID 选**测试号**（仓库已配 `touristappid`）。
3. 点「编译」。

不需要 `npm install`，不需要启动任何服务，断网也能跑完全流程。

### 顺便看后端（可选）

```bash
npm start                                # 终端 1：零依赖后端，127.0.0.1:3000
curl http://127.0.0.1:3000/api/health    # 确认已就绪
```

然后把 `utils/config.js` 里的 `dataSource` 从 `DATA_SOURCE.LOCAL` 改成 `DATA_SOURCE.REMOTE`，
重新编译。页面代码一行都不用改——所有取数与下单都走 `utils/repo.js` 这一层，
登录握手也由这一层自动完成。
开发者工具「详情 → 本地设置」需要勾上「不校验合法域名」（仓库已带 `urlCheck: false`，通常已勾好）。
接口清单、鉴权说明与真机联调方式见 [`server/README.md`](../server/README.md)。

> 不想改代码也行：在开发者工具的调试控制台执行
> `require('utils/config.js').setDataSource('remote')`。

数据会落到 `./.data/store.json`，**重启后端不丢**。想验证：
充值一笔 → `Ctrl-C` 停掉 → `npm start` → 余额还在。
要回到 1.4.0 的一次性内存模式用 `PERSIST=0 npm start`。

## 二、验收走查路径

按顺序走完这 16 步即覆盖全部关键路径。任意一步与「预期结果」不符都算缺陷。

| # | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 首次进入首页 | 顶部出现一次性演示声明提示条，点「✕」后不再出现 |
| 2 | 搜索「超充」，切筛选「有空闲」、排序「价格最低」 | 列表实时过滤与重排 |
| 3 | 右上角切「地图」 | 地图视图，点绿色 marker 弹出站点卡片，可一键回到当前位置 |
| 4 | 点「扫码」→ 确认「模拟扫码」 | 随机命中一把空闲枪并跳到对应站点详情，该枪已预选 |
| 5 | 详情页看分时电价，选一把空闲枪 → 开始充电 | 二次确认 → 启动动画 → 进入充电页；该枪变为「使用中」 |
| 6 | 观察充电页 | SOC 环形进度、时长、实时功率、费用每秒刷新（60 倍速） |
| 7 | 返回首页 / 订单页 | 底部出现绿色「充电中」悬浮条，「订单」tab 亮红点 |
| 8 | 回充电页 → 结束充电 | 进入结算页：费用明细 + 自动匹配优惠券 + 支付方式 |
| 9 | 结算页尝试左滑 / 点返回 | 弹窗提示订单会保留在「待支付」，避免误离开 |
| 10 | 选「余额支付」→ 确认支付（可连点） | 支付成功页；余额只扣一次、券核销、枪位释放。余额不足时会引导去钱包，充完返回结算页金额自动重算 |
| 11 | 订单 tab | 订单变「已完成」，可看账单、删除、再次充电 |
| 12 | 订单详情 → 申请开票 | 进入发票页并预选该单，填抬头/邮箱后提交，生成本地开票记录 |
| 13 | 我的 → 钱包 → 充值 100 元 | 余额增加并生成一条交易流水 |
| 14 | 我的 → 演示说明与隐私 | 运行配置（版本 / 数据源）、演示边界、本机数据清单、客服信息与分享按钮 |
| 15 | 开发者工具切「无网络」 | 提示「当前无网络，演示版可离线使用」，全流程照常 |
| 16 | 我的 → 清除本地数据 | 回到初始演示状态（含 2 条示例历史订单，首页提示条重新出现） |

其它可单独走查的页面：收藏、优惠券、开票记录。`project.config.json` 预置了 10 个编译模式，
可在工具右上角「普通编译」下拉框直接跳到指定页面；充电页与订单详情页需要运行时产生的
会话 / 订单 id，从订单列表点进去即可。

## 三、自动化验收

无需 `npm install`，Node ≥ 18：

```bash
npm run check    # 工程静态校验 + 144 个测试用例
npm run smoke    # 后端 41 项闭环检查（会自己在随机空闲端口起实例，数据落临时目录）
```

两条命令都不会往仓库里写东西：测试跑纯内存模式，冒烟用系统临时目录。

CI（`.github/workflows/ci.yml`）在每次 push 与 PR 上跑四个 job：

| Job | 内容 |
| --- | --- |
| `check` | Node 18 / 20 / 22 三个版本上跑 `npm run check` |
| `smoke` | 跑 `npm run smoke`，验证后端完整闭环（含登录与重启后数据仍在） |
| `docker` | 构建 `Dockerfile`、起容器并打健康检查 |
| `assets` | 重跑 `npm run build:assets`，生成物与仓库有 diff 即失败 |

`npm run validate` 会拦下的问题：JSON / JS 语法、页面四件套缺失、组件引用悬空、
WXML 标签未闭合、绑定的处理函数不存在、页面里点不到的死处理函数、未注册的页面目录、
静态资源缺失、三处版本号不一致、`project.config.json` 写成开发者工具不接受的形式、Markdown 死链。

## 五、已知限制

### 上线前必须解决（不是演示取舍，是真实缺口）

- **真实微信支付未接通**：`method: 'wechat'` 返回 `501`，余额支付带 `sandbox: true`。
  需要商户号、API 证书、APIv3 密钥、已备案回调域名——14 步接入清单见
  [`PRODUCTION.md` 第六节](PRODUCTION.md#六接入微信支付)。
- **真实充电桩协议未接入**：仍是 60 倍速仿真（`utils/charging.js` 的 `SIM_SPEED` 设为 `1` 即真实速度）。
- **小程序未认证、域名未配**：仓库用测试号 `touristappid`，`baseUrl` 指向 `127.0.0.1`。
  见 [`PRODUCTION.md` 第七节](PRODUCTION.md#七微信小程序后台要做的事)。
- **发票与客服没有真实通道**：发票页只生成本机记录，客服信息是 `utils/config.js` 里的演示数据。
- **不能多实例部署**：限流是单实例内存态，持久化是单机文件，多副本会互相覆盖。

### 演示的有意取舍

- **用户资料是演示数据**：未接入 `wx.getUserProfile` 与手机号授权，登录只用 openid 区分账号。
- **没有定位权限**：用户位置固定为深圳南山科技园，距离与 marker 基于该坐标计算。
- **默认数据源的数据在本机**：换设备或清缓存会回到初始演示状态。
- **截图与真机有细微差异**：`docs/screenshots/` 由无头 Chrome 渲染真实 WXML/WXSS 得到，
  地图与原生 `input` 以等价占位呈现。要看严格的真机效果请按第二节走查。

想换成自己的后端**不用改页面**：把 `utils/config.js` 的 `baseUrl` 指过去，
按 [`server/README.md`](../server/README.md) 的接口契约实现同名接口即可；
契约对不上的地方在 `utils/repo.js` 一处适配。
