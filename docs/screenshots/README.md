# 页面截图占位目录

本目录用于存放演示截图。截图需要在**微信开发者工具**模拟器中人工捕获（Node/CI 环境无法渲染小程序界面），
因此仓库中只保留本说明文件。

## 捕获步骤

1. 微信开发者工具导入本项目（AppID 选择「测试号」）并编译。
2. 按 README「5 分钟演示路径」逐步操作。
3. 在需要留档的界面点击模拟器右上角 **更多 → 截屏**（或直接对模拟器区域截图）。
4. 按下表命名保存到本目录，`README.md` 中的截图表格即可引用。

## 建议文件名

| 文件名 | 内容 |
| --- | --- |
| `01-home-list.png` | 首页列表视图（搜索 / 筛选 / 排序 / 站点卡片） |
| `02-home-map.png` | 首页地图视图（marker + 选中站点卡片） |
| `03-detail.png` | 站点详情（分时电价 + 充电枪宫格 + 已选枪底栏） |
| `04-charging.png` | 充电中（SOC 环形进度 + 实时数据） |
| `05-settle.png` | 结算页（费用明细 + 优惠券 + 支付方式） |
| `06-paid.png` | 支付成功页 |
| `07-orders.png` | 订单列表（状态分类 + 汇总） |
| `08-order-detail.png` | 订单详情账单与进度时间线 |
| `09-mine.png` | 我的（用户信息 + 钱包 + 统计 + 功能入口） |
| `10-wallet.png` | 钱包充值与交易流水 |

> 建议统一使用 iPhone X（375 × 812）模拟器尺寸，保证截图比例一致。
