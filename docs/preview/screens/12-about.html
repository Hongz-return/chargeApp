演示说明与隐私
充电桩小程序
演示版 v1.5.0
默认本地 mock 数据 · 开箱即用 · 可选连本地后端
演示声明
1
这是一个演示版小程序
用于完整展示充电桩业务流程：找站 → 选枪 → 扫码/手动启动 → 实时充电 → 结算支付 → 订单归档。
2
不会产生真实充电与真实扣款
充电按 60 倍速仿真，支付为本地 mock。余额、优惠券的变化只发生在本机，不对接任何支付通道。
3
不采集、不上传任何个人信息
默认数据源为本地，没有登录、不发起任何网络请求。昵称、手机号、车牌均为内置演示数据。切到 remote 后会用 wx.login 的 code 换一个登录令牌，仅用于区分账号，不读取头像与手机号。
4
数据只保存在本机
订单、钱包流水、收藏、优惠券、发票记录都写入微信小程序的本地 Storage，可在「我的 → 清除本地数据」一键删除。
5
无需联网即可完整体验
断网时全部功能不受影响。仓库另附一套零依赖后端（server/），把数据源切到 remote 即可联调，页面层无需改动。
6
正式上线还需要人工配置
后端已具备文件持久化、登录鉴权、限流与部署脚本，但微信支付需要商户号与证书，服务器域名需要备案与小程序后台配置。上线清单见仓库 docs/PRODUCTION.md。

演示边界
—没有真实支付：余额支付是演示沙箱，微信支付未接入商户号，不调用 wx.requestPayment。
—没有真实充电协议：充电按 60 倍速仿真，80% 后进入涓流，充满自动结束。
—没有真实开票：发票申请只生成本机记录，不对接税务或邮件通道。
—没有定位权限：用户位置固定为深圳南山科技园，距离与地图 marker 基于该坐标计算。
—用户资料是演示数据：未接入 wx.getUserProfile / 手机号授权，登录只用于区分账号。
—正式上线还需人工配置：微信认证小程序、备案域名、微信支付商户号，清单见仓库 docs/PRODUCTION.md。
