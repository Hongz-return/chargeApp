# 充电桩微信小程序

一个纯前端演示版「充电桩」微信小程序：查找附近充电站 → 查看桩详情并选择充电枪 → 模拟开始/结束充电并生成账单。所有数据来自本地 mock，**无需任何后端服务**。

## 如何运行

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开微信开发者工具，选择「导入项目」，目录选择本仓库根目录。
3. AppID 选择「测试号」（项目已配置 `touristappid`，无需注册小程序账号）。
4. 编译后即可在模拟器中体验完整流程。

## 页面说明

| 页面 | 路径 | 功能 |
| --- | --- | --- |
| 首页 | `pages/index` | 附近充电站卡片列表（名称、距离、快/慢充数量、单价、空闲数），支持「全部/快充/慢充」筛选与下拉刷新，点击卡片进入详情 |
| 桩详情页 | `pages/detail` | 充电站信息（地址、营业时间、停车说明、电费+服务费单价）与充电枪宫格；仅空闲枪可选，点击「开始充电」进入充电页 |
| 充电流程页 | `pages/charging` | 模拟充电进行中（实时电量、时长、功率、预计费用），点击「结束充电」后生成账单（电量、电费、服务费、合计），完成后返回首页 |

### 交互流程

```
首页（选站）→ 详情页（选枪）→ 开始充电 → 充电中（实时刷新）→ 结束充电 → 账单 → 返回首页
```

进行中的充电会话保存在 `app.globalData.chargingSession`。若已有进行中的订单，再次点击「开始充电」会提示前往查看，避免重复开单。

## Mock 数据说明

所有数据集中在 `utils/mock.js`：

- `STATIONS`：4 个充电站，每站包含地址、距离、营业时间、电费/服务费单价，以及若干充电枪（编号、快/慢充类型、功率 kW、状态）。
- 充电枪状态：`idle` 空闲（可开始充电）、`busy` 使用中、`offline` 维护中。
- 对外接口：
  - `getStations()`：返回按距离排序的站点列表，并附带空闲数/总数、快慢充数量、综合单价等汇总字段；
  - `getStationById(id)`：按 id 返回单个站点详情。

### 充电模拟规则

充电页按 **60 倍速**模拟（1 秒真实时间 = 60 秒充电时间），便于快速看到电量与费用变化。电量与费用均由 `功率 × 模拟时长` 实时推算：

- 电量（度）= 功率(kW) × 模拟时长(h)
- 费用 = 电量 × (电费单价 + 服务费单价)

倍率可在 `pages/charging/charging.js` 顶部的 `SIM_SPEED` 常量中调整（设为 `1` 即真实速度）。

├── pages/

│   ├── detail/          # 桩详情：站点信息 + 选枪
